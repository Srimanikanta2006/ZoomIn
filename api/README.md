# PreFlight API

FastAPI service for the Hugging Face Spaces Docker container. Install `requirements.txt` and run `uvicorn api.main:app --host 0.0.0.0 --port 7860` from the repository root. Configure `WEB_ORIGIN` to the exact web origin allowed by CORS.

Pydantic models for the application schema live in `models.py`. Verification routes live in `verification.py`: mock issuer outcomes are configured in `rules/mock_issuers.yaml`; `/verifications/qr` decodes local PDF QR codes; `/verifications/signature` validates embedded signatures against the local CCA roots; and `/mock-issuers/{issuer}/verify` supports latency and status injection. Each executed check is saved to `verifications` and the hash-chained audit log. Configure Supabase, apply migrations through `202610260004_verification_checks.sql`, and send a signed-in bearer token. Only synthetic documents belong in this demo.

Applicant draft creation, PDF upload, and submission use `/applicant/drafts`, `/applicant/upload`, and `/applicant/submit`. Apply `202610260009_applicant_uploads.sql` (or rerun `complete_setup.sql`) first. Uploads are limited to 20 MB and 500 pages; selectable-text PDFs receive a technical readability pre-check, while scanned PDFs remain blocked because OCR is not available on this path. A readable PDF is not a finding that its contents are valid; document details still require human verification. The upload route stores the PDF in the private `application-documents` bucket and registers its SHA-256 with the database.

`GET /graph` returns the synthetic association graph: institution/application/document nodes plus salted faculty, address, and signatory nodes. PDF page pHashes, normalized-text SimHashes, and file hashes support duplicate-document links. The response includes shared-faculty, shared-address, and duplicate-document findings with plain-language explanations. Raw faculty IDs, addresses, and signatory names are not returned. Graph reads require a signed-in scrutiny officer, regional officer, or admin and are appended to the hash-chained audit log; apply migration `202610260005_graph_audit.sql`. Set `GRAPH_HASH_SALT` to a private stable value when regenerating demo pseudonyms. The Hugging Face image includes only the synthetic ground-truth CSV and original PDFs used to build this graph.

`GET /eval/metrics` serves the latest generated evaluation report to signed-in officers and admins. It records the view in the hash-chained audit log; apply migration `202610260007_integrity_letters_handbook.sql`. Generate or refresh the report with `python eval/run.py` before building the Docker image.

Demo controls live under `/demo`: `/demo/status` reports issuer simulation and local-extraction fallback state, while `POST /demo/issuer-outage` toggles the synthetic issuer failure path for admins and writes a hash-chained event. The fallback banner is driven by `data/cache/demo_status.json`, written by the extraction pipeline after each run. Admin reset uses the `reset_demo_data` RPC from migration `202610260008_demo_mode.sql` and restores only the five seeded demo applications. Use `python scripts/warm_backend.py` to precompute synthetic PDF cache entries and touch the API before a presentation.
